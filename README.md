# papder-deepread

用于**深度解读论文**的最小模板，帮助快速产出结构化、高质量的论文分析。

## 解读目标

围绕一篇论文，输出不仅“讲了什么”，还要回答“为什么这样做、是否可信、如何复现、能否改进”。

## 深度解读结构（建议按顺序完成）

1. **一句话总结**
   - 论文要解决什么问题？核心贡献是什么？
2. **研究问题与动机**
   - 现有方法的痛点是什么？
   - 作者的假设是否合理？
3. **方法拆解**
   - 输入/输出、关键模块、训练/推理流程
   - 与基线方法的本质差异
4. **实验与证据**
   - 数据集、指标、对比方法是否公平
   - 消融实验是否支撑每个关键设计
5. **局限性与风险**
   - 适用边界、失败案例、潜在偏差
6. **复现与落地**
   - 复现所需条件（数据、算力、超参）
   - 在真实场景中如何改造与部署
7. **可改进方向**
   - 可验证的后续实验与工程优化建议

## 输出模板（可直接复制）

```text
论文标题：
研究问题：
核心贡献（3点内）：
方法要点：
实验结论是否充分：
主要局限：
复现难点：
可落地场景：
我的改进建议：
```
